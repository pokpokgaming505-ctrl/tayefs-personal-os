# Plugin changelog

## Gym 1.0.0 — 2026-11-01 (`gym-v1.0.0`)

- Editable 30-day workout and recovery calendar.
- Per-day exercise names, sets, reps, notes, and completion checkboxes.
- Optional per-plugin AI connection for nutrition questions.
- For users under 18, no numerical calorie or protein targets are requested from AI.

## AI Models 1.0.0 — 2026-11-01 (`ai-models-v1.0.0`)

- General assistant and configurable OpenAI-compatible model profiles.
- API keys remain in memory for one app session and are never included in JSON backups.
- Plugins connect only after the user chooses a model in that plugin.
