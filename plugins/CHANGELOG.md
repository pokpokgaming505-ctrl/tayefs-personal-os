# Plugin changelog

## Content Studio 1.0.0 — 2026-11-03 (`content-studio-v1.0.0`)

- Idea capture and a production pipeline for YouTube, Shorts, Instagram, TikTok, posts, threads, and articles.
- Editable audience, goal, research, titles, hook, outline/storyboard, script, shot list, cover, caption, hashtags, and publish date.
- Short explainer, long-form video, and carousel/thread templates plus a production checklist.
- Optional explicit connection to a selected AI model for a draft suggestion; saved briefs remain on-device.

## Gym 1.1.0 — 2026-11-03 (`gym-v1.1.0`)

- Published a downloadable, checksum-verified plugin package with separate download and Add steps.
- Kept the editable monthly plan, recovery days, sets/reps, and completion tracking in the Gym adapter.

## Gym 1.0.0 — 2026-11-01 (`gym-v1.0.0`)

- Editable 30-day workout and recovery calendar.
- Per-day exercise names, sets, reps, notes, and completion checkboxes.
- Optional per-plugin AI connection for nutrition questions.
- For users under 18, no numerical calorie or protein targets are requested from AI.

## AI Models 1.1.0 — 2026-11-03 (`ai-models-v1.1.0`)

- Published a downloadable, checksum-verified package with separate download and Add steps.
- Retained session-only API keys and per-plugin model selection.

## AI Models 1.0.0 — 2026-11-01 (`ai-models-v1.0.0`)

- General assistant and configurable OpenAI-compatible model profiles.
- API keys remain in memory for one app session and are never included in JSON backups.
- Plugins connect only after the user chooses a model in that plugin.
