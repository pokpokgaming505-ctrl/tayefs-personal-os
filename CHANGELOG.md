# Changelog

Each app version stays in a separate GitHub Release with its installers. Plugin source snapshots stay available from their own tags in the same repository.

## 0.2.0 — 2026-11-01

- Rebranded the Windows and Android app as TAYEF'S with a new monogram and launcher/installer icon.
- Added a Bright theme plus saved theme, text-size, and font-style preferences.
- Added a built-in plugin catalog with independently versioned Gym and AI Models plugins.
- Added the editable 30-day Gym plan and explicit AI model selection for Gym nutrition ideas.
- Added the AI assistant, OpenAI-compatible model profiles, session-only API keys, and consent before sending prompts.
- Kept the existing app ID and migrated v0.1.0 local data and backups forward.

## 0.1.0 — 2026-10-31

- First Northstar desktop and Android app release.
- Daily dashboard, health check-ins, study timer and log, project board, reading shelf, idea notes, and weekly review.
- Three visual styles, on-device storage, and JSON backup/restore.
- Windows x64 installer and Android debug APK.
