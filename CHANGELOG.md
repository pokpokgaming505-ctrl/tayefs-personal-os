# Changelog

Each published version is kept as a separate GitHub Release with its Windows installer and Android APK.

## 0.1.0 — 2026-10-31

- First Northstar desktop and Android app release.
- Daily dashboard, health check-ins, study timer and log, project board, reading shelf, idea notes, and weekly review.
- Three visual styles, on-device storage, and JSON backup/restore.
- Windows x64 installer and Android debug APK.
